# UU-AAP v0.1 — пакет публичного обсуждения

Это готовая стартовая структура репозитория для **Протокола усиленного авторства и ответственности**.

Главный файл: `SPEC.md`.  
Русское пояснение: `SPEC.ru.md`.  
Формальная схема: `schema/uu-aap-manifest.schema.json`.

Первый публичный раунд предложено провести с **22.08.2026 по 06.10.2026**.

Для обсуждения полезно завести метки:

- `normative`
- `privacy`
- `security`
- `authorship`
- `c2pa`
- `concept-lineage`
- `registry`
- `legal`
- `editorial`
- `breaking-change`

Главная просьба к участникам — не спорить о том, «хорош или плох ИИ», а проверять, достаточно ли протокол делает происхождение, участие и ответственность понятными и проверяемыми.
