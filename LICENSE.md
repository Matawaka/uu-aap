# Licensing Proposal for Public Draft v0.1

The repository is published for open review under the following proposed licensing split:

- specification prose and explanatory documents: **Creative Commons Attribution 4.0 International (CC BY 4.0)**;
- JSON Schemas and future reference implementation: **Apache License 2.0**.

Before a formal tagged release intended for external implementation, the repository SHOULD include the complete canonical license texts and a contribution policy reviewed for the selected governance venue.
