# Circumstantial Provenance / Evidence Independence v0.1

Provider-neutral, non-actuating profile for assessing bounded origin/continuity claims from plural evidence without collapsing agreement into identity, authorship, causality, responsibility, liability, or canonical truth.

## Canonical path

`Evidence Items -> Source/Dependency Classification -> Lineage/Contradictions -> Scoped Provenance Assessment -> supported | partially_supported | inconclusive | contradicted`

## Required invariants

- Circumstantial Agreement != Proven Origin.
- Shared Correlation != Independent Evidence.
- Repeated Copy != Multiple Independent Sources.
- Missing Link != Proof of Discontinuity.
- No Missing Link != Proof of Complete History.
- Hash Match != Authorship or Intent.
- Provenance Support != Causal Attribution != Responsibility != Liability.
- Evidence Count != Evidence Independence.
- Assessment Result != Canonical Verdict.
- Inconclusive != Failed/False/Refused.

Evidence independence is categorical metadata through `independence_group` and explicit `dependency_refs`; no scalar trust/independence score is defined.

Cross-context correlation is disabled by default. Evidence may be commitment-only where full payload retention is unnecessary.

This profile composes with `protocols/integration/personal-sovereign-root/v0.1` but does not create identity-resolution or root-control authority.

## Non-effects

No identity lookup, external correlation, profile construction, surveillance logging, causal adjudication, liability assignment, KONTUR mutation, external action, authority transfer, release/tag, history rewrite, or canonical verdict is performed by this profile.
