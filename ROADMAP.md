# Roadmap

## Phase 0 — Public Draft
**22 Aug – 6 Oct 2026**

- publish v0.1;
- open Issues and Discussions;
- recruit external reviewers from publishing, standards, privacy and AI governance;
- collect failure cases;
- map core fields to C2PA and W3C VC;
- publish issue disposition plan.

## Phase 1 — v0.2 + test vectors
**October–November 2026**

- disposition public comments;
- stabilize JSON Schema;
- define canonical serialization and signature profile;
- add formal dispute and appeal objects;
- create 10–20 valid/invalid test manifests;
- publish a conformance test matrix.

## Phase 2 — Reference implementation
**November 2026–January 2027**

- CLI to create, validate and inspect manifests;
- artifact hashing;
- C2PA proof of concept for EPUB/PDF;
- signed reviewer-attestation example;
- static browser verifier.

## Phase 3 — Pilot registry
**Q1 2027**

- public manifest registry;
- immutable version history;
- reviewer attestations;
- corrections, disputes and appeals;
- first author/publisher pilots;
- explicit anti-surveillance deployment guidance.

## Phase 4 — Standards incubation
**Q2–Q4 2027**

- seek independent implementations;
- run interoperability tests;
- evaluate neutral standards incubation;
- publish governance, security and accessibility review.
