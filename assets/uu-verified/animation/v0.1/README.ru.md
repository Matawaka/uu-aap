## Что опубликовано

В ветку GitHub добавлены код генерации, код извлечения форм, временная шкала, манифест, отчёт локальной сборки и документация. **Передача самих GIF, MP4, PNG и входных масок не завершена.** Попытка передать данные исходного изображения была заблокирована инструментом. Здесь нет обходного workflow загрузки, публикации через сторонний сервис, релиза или автоматического merge.

Полный архив, приложенный в разговоре, содержит все файлы из `artifact-manifest.json`: обе GIF, MP4, исходное изображение, маски форм, превью и код. Манифест описывает содержимое архива, но сам по себе не доказывает наличие этих файлов в GitHub. После переноса нужно запустить проверку и только затем обновлять статус публикации.

## Что входит в полный комплект

`UU_verified.gif` — 768 x 768, 16,5 секунды, бесконечный повтор, 530 закодированных кадров. `UU_verified_once.gif` — 15,5 секунды, 481 кадр, одно проигрывание с остановкой на финальном логотипе. `UU_verified.mp4` — 768 x 768, 50 кадров/с. `UU_verified_final.png` — неподвижный финал.

В `source/` находятся воспроизводимый генератор, извлечение форм, точное исходное изображение `reference.png`, маски глаз и букв и версии зависимостей. Формы букв извлечены из изображения; шрифтовых файлов в комплекте нет.

Две одинаковые U смотрят по сторонам и замирают. Рот возникает из точки, вытягивается в линию и раскрывается в овал. Восемь букв `verified` появляются последовательно с отскоком и затухающим покачиванием соседей. После паузы надпись поднимается, а U опускаются с упругой деформацией. При перестановке овал временно сужается, а глаза расходятся, освобождая проход. Буквы ограничены областью рта, элементы — внутренней областью круга. Полная последовательность — в `timeline.json`.

## Повторить сборку

Команды выполняются из папки полного комплекта. Сначала установить указанные Python-зависимости, системную библиотеку Cairo и, для видео, FFmpeg:

```sh
python -m pip install -r source/requirements.txt
python source/verify_package.py
python source/build_animation.py --output rendered --video --require-exact
```

Чтобы заново извлечь маски из точного исходного изображения:

```sh
python source/extract_masks.py source/reference.png
```

Чтобы получить все 825 PNG-кадров с равным шагом, включая паузы:

```sh
python source/build_animation.py --output rendered-frames --frames --require-exact
```

Генератор — переносимая адаптация использованного ранее скрипта: сохранены формулы движения, маски, палитра и кодирование. На зафиксированной локальной среде повторно получено точное совпадение SHA-256 обеих GIF и MP4 с переданными файлами. Это локальное воспроизведение, не независимое ревью и не результат GitHub CI. При несовпадении `--require-exact` останавливает сборку; старые артефакты нельзя незаметно подменять.
