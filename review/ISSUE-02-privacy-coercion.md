# Issue proposal: Define minimum anti-surveillance protections

UU-AAP rejects mandatory biometric typing evidence, continuous screen recording and complete prompt disclosure for ordinary conformance.

**Questions:**

1. Are these prohibitions strong enough?
2. What additional evidence practices could become coercive?
3. Should implementations be forbidden from advertising surveillance extensions as “higher UU-AAP authenticity”?
4. How should private audit evidence be retained and deleted?
