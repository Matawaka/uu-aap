# Issue proposal: Test D/T/V/R conformance language

Profiles D/T/V/R are intended to describe evidence and process maturity, not work quality.

**Questions:**

- Do the labels imply an unintended hierarchy of artistic or moral value?
- Should Reviewed be a separate attestation rather than a profile?
- Is “Verifiable” too broad if factual truth is not being verified?
- What reader-facing wording avoids a false trust badge?
