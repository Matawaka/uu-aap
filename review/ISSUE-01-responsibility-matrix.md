# Issue proposal: Validate the responsibility matrix against real publishing workflows

The draft replaces a single “final responsibility” declaration with scoped responsibility.

Please test whether the current scopes are sufficient for:

- single-author books;
- multi-author books;
- ghostwriting/editing workflows;
- publisher-led editing;
- AI-assisted research;
- independent fact checking;
- translations and derivative editions.

**Question:** Which scopes are missing, redundant or legally misleading?

Please include a concrete workflow when possible.
