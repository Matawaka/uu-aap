# Issue proposal: Map UU-AAP claims to C2PA 2.4

UU-AAP intends to reuse C2PA for artifact provenance and cryptographic binding.

Please propose:

- which UU-AAP objects belong in a C2PA assertion;
- which should remain external and referenced;
- how repository receipts should be used;
- EPUB/PDF implementation constraints;
- what should never be embedded for privacy reasons.
