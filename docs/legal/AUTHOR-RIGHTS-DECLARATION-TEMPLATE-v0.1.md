# UU-AAP Author & Rights Declaration Template v0.1

**Template status:** reusable private-evidence form  
**Public-repository rule:** do not commit a completed form if it contains addresses, signatures, contract text, passport data, employer/customer confidential data or other unnecessary personal information.

This template supports an IP registration record. It does not itself create authorship, transfer rights, certify identity or replace a contract/assignment where one is legally required.

`declaration != automatic ownership`

`repository contribution != automatic assignment`

`AI assistance != automatic human authorship`

## J. Attestation

The declarant should attest, in the private signed form used for the filing evidence package, that the information is accurate to the best of their knowledge and that known uncertainties have not been intentionally omitted.

The public repository should normally retain only:

- declaration type/version;
- applicable IP object ID;
- non-sensitive outcome;
- date;
- cryptographic digest/reference of the private completed declaration;
- successor-state linkage.

Do not treat the public digest as proof that the declaration's factual statements are true; it proves only binding to the retained private artifact when the digest is correctly verified.
