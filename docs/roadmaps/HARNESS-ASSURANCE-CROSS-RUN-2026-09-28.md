## Прямой сетевой путь

Повторная локальная попытка завершилась COLLECTION_INCOMPLETE: transport_unavailable,
одна попытка запроса, ноль байтов ответа. Это не успешный HTTP-сбор.
Добавлен один отдельный workflow потребителя: точный head checkout, Python 3.13,
три существующих тестовых входа, затем один ограниченный анонимный GET-сбор R2.
Ожидания строятся из закреплённого исторического manifest, не из отчёта.
Новые токены и секреты не используются; HA-1 workflow и main не меняются.
Состояние этой записи: LOCAL_CROSS_RUN_CHECKED_HOSTED_PENDING.
Фактический облачный результат записывается после чтения run/jobs/артефакта.
