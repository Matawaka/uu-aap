## Выполнено

Добавлен один ограниченный сборщик метаданных GitHub и сравнение двух пакетов.
Сборщик запрашивает конкретную попытку до и после пагинации jobs/artifacts.
URL конструируются из отдельно заданных ожиданий, ссылки из ответов не выполняются.
Читатель по-прежнему получает архивы отдельно и ничего из evidence не исполняет.
Сравнение заново оценивает обе стороны; разные попытки не становятся одной задачей,
пропавший архив не считается доказанной регрессией кода.

Локально прошли 64 прежних + 55 новых тестов, шесть CLI-проверок. На выборке
сохранённого run 36316768214/1 — 186 совпадений; повторная выборка даёт
NO_OBSERVED_CHANGE. Отдельный синтетический пример без py313.zip даёт EVIDENCE_LOSS.
Это новое чтение прежнего CI, а не повторное облачное исполнение его 160 тестов.

## Явное ограничение текущей среды

Прямой HTTPS из среды выполнения недоступен: DNS lookup завершился ошибкой.
Live HTTP-путь сборщика вернул COLLECTION_INCOMPLETE, exit 2, а не успех.
Данные прочитаны подключённым GitHub-инструментом: две страницы jobs и две artifacts,
конкретная попытка до/после. В локальный replay перенесены выбранные поля ответов.
Происхождение CONNECTOR_SELECTED_JSON_REPLAY, не полные HTTP-ответы и не подпись.
Автоматическая нормализация/пагинация проверена на этом replay и синтетических случаях;
положительное end-to-end испытание прямого HTTP ещё не состоялось.

| Направление | Разработка | Что ещё не заявлено |
| --- | --- | --- |
| HA-1 | Зафиксирован, не изменён | Независимая приёмка не завершена |
| HA-2 | Сборщик + offline reader + сравнение работают на replay/архивах | Успешный live HTTP smoke, скачивание ZIP сборщиком, аутентификация источника |
| HA-3 | Не начат | Синтетические отказы не подменяют эксплуатационный finding |
| HA-4 | Отложен | Экономический эксперимент не выполнялся |

## Следующий полезный шаг

Провести положительный GET-only smoke в среде с разрешённым сетевым доступом,
без новых credentials. Затем проверить второй завершённый CI-пакет с отдельно
выбранными ожиданиями, чтобы испытать сравнение разных запусков, а не одной версии.
Не расширять компонент до универсального сборщика и не менять зафиксированный HA-1.
Разработка продолжается отдельно от приёмки; merge/deploy/полномочия не изменяются.
