## Следующий проверяемый результат

Одна новая path-scoped CI-проверка должна исполнить существующий HA-1 на точном
head SHA, в Python 3.12 и 3.13. Состав: 114 исходных тестов, 31 тест самой CI-обвязки,
7+8 намеренно повреждённых реализаций, исторический статический валидатор HA-0.
Код анализатора, исходные тесты, 40 ожиданий и frozen inputs сохраняются без изменений.

Пустой набор, пропуск теста, неполное исполнение или неверный SHA не могут считаться
успехом. Отчёт и журналы сохраняются отдельно от checkout. Облачный прогон считается
наблюдавшимся только после чтения реального run/jobs; наличие workflow этого не доказывает.

| Этап | Состояние этой записи | Следующий барьер |
| --- | --- | --- |
| HA-0 | BOUNDED_SELF_REVIEW_RECORDED | Независимое принятие дизайна не заявлено. |
| HA-1 | CI_WIRING_LOCAL_CHECKED_HOSTED_RESULT_PENDING | Проверить реальный CI run на точной ревизии; затем независимое ревью. |
| HA-2 | NOT_STARTED | Реальный источник evidence не подключать автоматически. |
| HA-3 | NOT_STARTED | Локальные ошибки прототипа не засчитываются за эксплуатационный finding. |
| HA-4 | DEFERRED | Сравнение стоимости не запускалось. |

Эта таблица фиксирует предзапусковое состояние, а не выдумывает будущий CI PASS.
Последующий результат должен ссылаться на конкретный run/attempt в PR и на артефакт.

## Ограничение изменения

Добавляется только отдельный workflow и его локальная тестовая обвязка.
Существующие workflows, Core, permissions вне нового job, branch protection,
продукты, основные родмапы, main и исторические receipts не меняются.
Новый job имеет только contents:read, без repository secrets; не используется
pull_request_target, credentials не сохраняются в checkout. Установка Python,
checkout и загрузка артефактов используют сеть: это не изолированная ОС-песочница.

Облачное исполнение не превращается в независимый аудит. Самопроверка не выдаёт
permit, не разрешает merge/deploy и не переводит проект на HA-2.
