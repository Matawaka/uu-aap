[Captured CI Evidence Reader](../../tools/ci_evidence_reader/v0_1/README.md) — один
локальный читатель уже сохранённых архивов run 36316768214, attempt 1. Он отделяет
согласованность CI-пакета от доказанности полного процесса; не добавляет отсутствующие
стадии и не считает итог разрешением на действие. Получены JSON и HTML на русском.

пакет согласован по 185 сравнениям, семь более сильных утверждений остаются
неустановленными. Это чтение прежнего CI, не новый запуск его 160 методов.

## Следующие важные задачи

1. Один отдельный read-only сборщик для этого формата GitHub: наблюдения run/jobs/
   artifacts, пагинация, источник и момент сбора; не расширять права и не смешивать
   сеть с чистым offline reader. Сначала зафиксировать контракт и бюджет чтения.
2. Сравнение двух сохранённых пакетов по типизированным идентификаторам, чтобы видеть
   новый пропуск, изменение состава и смену проверенной ревизии без потери исходников.
3. При наличии выбранного потребителя — показать такой отчёт в Workbench, сохранив
   разницу между lifecycle, evidence и authority; это не автоматическое возобновление продукта.

Человек нужен для невыводимых продуктовых решений, новых расходов/доступов,
существенных внешних эффектов и итоговой оценки полезности. Обычная обратимая
разработка продолжается. Заблокированный вызов review-интеграции не повторяется
и не обходится. Merge, deploy, ключи, Core и прочие продуктовые ветки не меняются.
