# Exploratory Architecture Sufficiency Audit v0.1

Status: **bounded research audit / read-only / non-promoting**. Tracking: #885.

This audit asks whether four exploratory concepts require new reusable infrastructure at the exact accepted repository frontier. It does not implement SCAF, CPOT, Immune Tremor, or Conscious AI and does not change their `EXPLORATORY` backlog classification.

NEW_COMPONENT_CANDIDATE = 0

Overall:

`EXPLORATORY_SUFFICIENCY_NO_NEW_COMPONENT_CURRENTLY_JUSTIFIED`

This is a bounded current result, not a permanent absence claim. Future independent field/interoperability evidence may justify a successor audit.

## SCAF

Core already owns `State / Evidence -> Possibility / Availability -> Intent`; capability selection and fresh availability are also reusable interfaces. Existing counterfactual machinery is explicitly model-relative and currently bounded to an exact local Git transition, not a physical-world causal model.

The current architectural gap is therefore **source-side**: a future provider-neutral world/physical/causal-property model would need an adapter/projection into existing State/Availability/Capability interfaces. The audit does not authorize such an adapter and does not create a second Possibility/Availability primitive.

## CPOT

Successor/frontier identity, append-only historical assurance, future-representation supersession, and No Silent Reinterpretation already exist. CPOT currently adds a useful **transition-policy vocabulary** for dual evaluation, translation and continuity across a rule/model boundary, not evidence of a missing state/successor primitive.

A CPOT profile must preserve predecessor evidence and uncertainty; a later successor cannot retroactively upgrade historical assurance.

## Immune Tremor

FCL already distinguishes `SUSPECTED_STALL` from active progress and terminal closure. Event-Responsive Dormancy already provides wake/re-evaluation without restoring old authority. Existing pre-action/action/observation interfaces can separately govern a diagnostic perturbation.

Therefore the current safest architecture is composition:

```text
FCL stall/ambiguity evidence
 -> current evidence/intent/authority checks
 -> separately admitted minimal reversible diagnostic action
 -> observation / successor evidence
 -> re-evaluation
```

`SUSPECTED_STALL != Failure Proof` and `Diagnostic Perturbation != ActionPermit != Causal Proof`. No polling/self-authorizing tremor is introduced.

## Conscious AI

This audit uses **operational conscious agency only**: bounded situational modelling, role/limit awareness, alternatives, question/attention/re-entry candidates, admissible action selection, bounded explanation, and outcome update.

The existing stack already contains most of those primitives. The remaining generic self-generated question/attention/re-entry interface is **not established** by current reusable evidence; the existing Non-Binding Attention implementation is KONTUR/pilot-specific and is not promoted.

The appropriate current architecture is an operational conformance/assessment profile, not a new primitive. Nothing here proves phenomenal consciousness, qualia, sentience, selfhood, personhood, moral status, or autonomous authority.
