# UU Society v0.1 — формальная модель состояний

**Статус:** экспериментальная формальная модель  
**Полномочие:** только описательное; не создаёт Stable Core promotion, юридических последствий, runtime authority или активации политики  
**Связанный backlog:** #1021 и #943

## Назначение

Этот каталог начинает формальное моделирование социально-экономического слоя UU Society в виде машиночитаемых контрактов состояния и переходов.

Модель сознательно консервативна. Она формализует только то, что можно утверждать без ложного предположения о существовании универсального числового рейтинга доверия, универсальной функции ценности или автоматического определения «хорошего» человека.

Основная цепочка:

```text
Actor
  -> Intent
  -> Need
  <-> Capability / Resource
  -> Match
  -> Commitment
  -> Evidence + TrustState + RiskHarmEnvelope
  -> ARAEState
  -> ActionLease
  -> Action
  -> Outcome
  -> Harm / RuleViolation (orthogonal)
  -> Receipt
  -> Contribution / Repair / Dispute
  -> Delegation / GovernanceRule
  -> FailurePattern / Learning
```

## Файлы

- `uu-society-state.schema.json` — JSON Schema Draft 2020-12 полного снимка состояния;
- `uu-society-transition.schema.json` — универсальное событие перехода, связанное с evidence и authority;
- `uu-society-model.manifest.json` — машиночитаемый каталог сущностей, инвариантов, правил взаимодействия и разрешённых переходов;
- `README.md` — английское описание;
- `README.ru.md` — русское описание;
- `examples/minimal-mutual-aid.snapshot.json` — минимальный пример состояния взаимопомощи;
- `examples/minimal-mutual-aid.transition.json` — минимальный пример допустимого перехода.

## Порядок чтения агентом

1. Сначала прочитать `uu-society-model.manifest.json`.
2. Структуры сущностей разрешать через `uu-society-state.schema.json`.
3. Переход состояния проверять одновременно по enum состояния сущности и по `transition_catalog`.
4. `interaction_rules` и `invariants` трактовать как семантические ограничения, которые JSON Schema не может полностью обеспечить.
5. Никогда не выводить из валидности схемы юридический эффект, моральную правильность, истинность идентичности, виновность или implementation authority.

## Основные решения v0.1

- Доверие контекстно и многомерно; универсального числового социального рейтинга нет.
- Базовый уровень прав не зависит от доверия и вклада.
- Исторические персональные данные не равны текущей агентности.
- ARAE ограничивает достижимые последствия, а не человеческое достоинство.
- Память ошибок принадлежит обучению системы и не является пожизненной стигмой человека.
- Вклад по умолчанию нефунгибелен; v0.1 не присваивает ему универсальную обменную стоимость.
- `Harm` и `RuleViolation` являются самостоятельными ортогональными сущностями состояния: вред не доказывает нарушение, а нарушение не доказывает вред.
- Валидность перехода требует актуальных evidence/authority именно на границе перехода.
- Полномочия при делегировании монотонно не расширяются: `child authority ⊆ parent authority`.
- Локальное управление остаётся подчинено конституционному Rights Floor.

## Двуязычность для машинного чтения

JSON Schema использует стандартные английские ключи и расширения `x-title-ru` / `x-description-ru`. В manifest семантические инварианты представлены одновременно полями `text_en` и `text_ru`.

## Граница утверждений

Валидность по схеме означает только структурное соответствие экспериментальной модели. Она не доказывает фактическую истинность, достаточность evidence, наличие текущего authority, согласие, справедливость, юридический эффект или общественную легитимность.


## Анализ мета-устойчивости

Исполняемая модель также содержит population/timeline suite мета-устойчивости. Он сознательно не вычисляет единый «индекс здоровья общества», а проверяет независимые структурные режимы отказа:

- повторное использование одного evidence текущего контроля как множителя нескольких PERSON-идентичностей;
- ротацию координированных участников, стирающую повторяющийся межсубъектный паттерн извлечения;
- самолегитимацию governance внутри замкнутой коалиции без независимого пересмотра;
- длительные ограничения, сохраняющиеся по инерции без свежего evidence или пути восстановления;
- попытки свернуть контекстное доверие в универсальный рейтинг человека.

Обнаружение мета-паттерна является основанием для пересмотра, а не доказательством индивидуальной виновности.


## Детерминированная популяционная симуляция

Лабораторный слой v0.1 способен прогонять фиксированные синтетические популяции через тысячи взаимодействий, используя детерминированный генератор на основе счётчика SHA-256.

Reference fixtures разделяют разные режимы отказа вместо сведения их к одному непрозрачному показателю:

- P00 — сбалансированный baseline;
- P01 — коалиционное извлечение и неравенство доступа;
- P02 — концентрация provider/authority через положительную обратную связь;
- P03 — длительное давление ограничений при подавлении вреда containment-механизмом;
- P04 — неудовлетворённые потребности при одновременно простаивающих возможностях;
- P05 — высокое давление вреда при слабом containment.

Симулятор выдаёт несколько независимых агрегированных наблюдений. Пересечение диагностического порога является основанием для архитектурного пересмотра, а не суждением об отдельном человеке.


## Исследование фазового пространства

UU Society v0.1 теперь включает детерминированные декартовы sweeps по параметрам популяционной модели. Первый reference sweep W00 изменяет долю adversarial Actors, вероятность adversarial Repair, длительность containment, силу feedback при выборе provider и willingness/координационное трение.

Клетка классифицируется только множеством независимых диагностических сигналов. Соседние клетки с различными наборами сигналов образуют эмпирические boundary edges. Так возникает первая карта смены режимов модели без сведения общества к одному числу и без объявления одной комбинации параметров универсальным оптимумом.
