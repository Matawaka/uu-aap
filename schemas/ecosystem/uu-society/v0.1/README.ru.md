# UU Society v0.1 — формальная модель состояний

**Статус:** экспериментальная формальная модель  
**Полномочие:** только описательное; не создаёт Stable Core promotion, юридических последствий, runtime authority или активации политики  
**Связанный backlog:** #1021 и #943

## Назначение

Этот каталог начинает формальное моделирование социально-экономического слоя UU Society в виде машиночитаемых контрактов состояния и переходов.

Модель сознательно консервативна. Она формализует только то, что можно утверждать без ложного предположения о существовании универсального числового рейтинга доверия, универсальной функции ценности или автоматического определения «хорошего» человека.

Основная цепочка:

```text
Actor
  -> Intent
  -> Need
  <-> Capability / Resource
  -> Match
  -> Commitment
  -> Evidence + TrustState + RiskHarmEnvelope
  -> ARAEState
  -> ActionLease
  -> Action
  -> Outcome
  -> Harm / RuleViolation (orthogonal)
  -> Receipt
  -> Contribution / Repair / Dispute
  -> Delegation / GovernanceRule
  -> FailurePattern / Learning
```

## Файлы

- `uu-society-state.schema.json` — JSON Schema Draft 2020-12 полного снимка состояния;
- `uu-society-transition.schema.json` — универсальное событие перехода, связанное с evidence и authority;
- `uu-society-model.manifest.json` — машиночитаемый каталог сущностей, инвариантов, правил взаимодействия и разрешённых переходов;
- `README.md` — английское описание;
- `README.ru.md` — русское описание;
- `examples/minimal-mutual-aid.snapshot.json` — минимальный пример состояния взаимопомощи;
- `examples/minimal-mutual-aid.transition.json` — минимальный пример допустимого перехода.

## Порядок чтения агентом

1. Сначала прочитать `uu-society-model.manifest.json`.
2. Структуры сущностей разрешать через `uu-society-state.schema.json`.
3. Переход состояния проверять одновременно по enum состояния сущности и по `transition_catalog`.
4. `interaction_rules` и `invariants` трактовать как семантические ограничения, которые JSON Schema не может полностью обеспечить.
5. Никогда не выводить из валидности схемы юридический эффект, моральную правильность, истинность идентичности, виновность или implementation authority.

## Основные решения v0.1

- Доверие контекстно и многомерно; универсального числового социального рейтинга нет.
- Базовый уровень прав не зависит от доверия и вклада.
- Исторические персональные данные не равны текущей агентности.
- ARAE ограничивает достижимые последствия, а не человеческое достоинство.
- Память ошибок принадлежит обучению системы и не является пожизненной стигмой человека.
- Вклад по умолчанию нефунгибелен; v0.1 не присваивает ему универсальную обменную стоимость.
- `Harm` и `RuleViolation` являются самостоятельными ортогональными сущностями состояния: вред не доказывает нарушение, а нарушение не доказывает вред.
- Валидность перехода требует актуальных evidence/authority именно на границе перехода.
- Полномочия при делегировании монотонно не расширяются: `child authority ⊆ parent authority`.
- Локальное управление остаётся подчинено конституционному Rights Floor.

## Двуязычность для машинного чтения

JSON Schema использует стандартные английские ключи и расширения `x-title-ru` / `x-description-ru`. В manifest семантические инварианты представлены одновременно полями `text_en` и `text_ru`.

## Граница утверждений

Валидность по схеме означает только структурное соответствие экспериментальной модели. Она не доказывает фактическую истинность, достаточность evidence, наличие текущего authority, согласие, справедливость, юридический эффект или общественную легитимность.


## Анализ мета-устойчивости

Исполняемая модель также содержит population/timeline suite мета-устойчивости. Он сознательно не вычисляет единый «индекс здоровья общества», а проверяет независимые структурные режимы отказа:

- повторное использование одного evidence текущего контроля как множителя нескольких PERSON-идентичностей;
- ротацию координированных участников, стирающую повторяющийся межсубъектный паттерн извлечения;
- самолегитимацию governance внутри замкнутой коалиции без независимого пересмотра;
- длительные ограничения, сохраняющиеся по инерции без свежего evidence или пути восстановления;
- попытки свернуть контекстное доверие в универсальный рейтинг человека.

Обнаружение мета-паттерна является основанием для пересмотра, а не доказательством индивидуальной виновности.


## Детерминированная популяционная симуляция

Лабораторный слой v0.1 способен прогонять фиксированные синтетические популяции через тысячи взаимодействий, используя детерминированный генератор на основе счётчика SHA-256.

Reference fixtures разделяют разные режимы отказа вместо сведения их к одному непрозрачному показателю:

- P00 — сбалансированный baseline;
- P01 — коалиционное извлечение и неравенство доступа;
- P02 — концентрация provider/authority через положительную обратную связь;
- P03 — длительное давление ограничений при подавлении вреда containment-механизмом;
- P04 — неудовлетворённые потребности при одновременно простаивающих возможностях;
- P05 — высокое давление вреда при слабом containment.

Симулятор выдаёт несколько независимых агрегированных наблюдений. Пересечение диагностического порога является основанием для архитектурного пересмотра, а не суждением об отдельном человеке.


## Фазовый ландшафт v0.3

В дополнение к bounded replay-sweep v0.2 UU Society содержит более крупные детерминированные карты ландшафта.
W00 исследует пять взаимодействующих осей устойчивости, а W01 отдельно исследует коалиционный захват. Анализатор фиксирует соседние фазовые boundary edges и Pareto-frontier по независимым измерениям потерь. Попадание клетки в frontier не означает «оптимальное общество» — только отсутствие доминирования по явно указанным метрикам.


## Эндогенная адаптация v0.4

Actors теперь могут менять будущий выбор взаимодействий на основании накопленной синтетической истории. Адаптация хранится на контекстных рёбрах отношений, а не в одном глобальном рейтинге человека. Успешное взаимодействие может усиливать локальную связь, harm/breach — сужать её, Repair — восстанавливать, а bilateral reciprocity — создавать трение против повторяющегося одностороннего извлечения.

Заведомо плохая политика глобального обобщения сохранена только как сравнительный эксперимент.


### Результат адаптивного эксперимента

Одной двусторонней памяти недостаточно против ротационного free-riding: между A04 и A05 extractor imbalance p95 изменился лишь с 129 до 127. В A06 контекстно ограниченное evidence вклада снизило его до 28, но общая fulfilled-rate упала до 67,1%, открыв новый failure mode чрезмерного трения. В A07 явное исключение protected need сохранило 98,2% удовлетворения потребностей для легитимно асимметричных получателей.

Это уточняет правило проекта: **распределённая взаимность должна видеть ротацию, не превращаясь в универсальную репутацию, а реальная потребность должна оставаться отличимой от extractive behavior.**


## Эндогенная эволюция стратегий v0.5

Следующий экспериментальный слой убирает заранее назначенные типы adversarial/extractor. Actors начинают с равных оценок стратегий и обучаются на собственных синтетических результатах. Поэтому cooperation, extraction, repair, exit и coalition могут расширяться или исчезать как следствие среды.

Стратегия является временной поведенческой политикой, а не идентичностью или моральной классификацией человека.


### Результаты эволюции стратегий

Эксперименты v0.5 показали различие между **частной выгодой** и **социальной обучаемостью**. Даже сильные прямые награды сами по себе не сделали cooperation, Repair или coalition доминирующими. После появления анонимного агрегированного evidence результатов стратегии cooperation достигла 88,3% в tail, а coalition — 85%. Repair оказался иным случаем: в среде с высоким harm evidence распространило прежде всего EXIT, и доля выхода достигла 71,7%.

Это указывает на более глубокую задачу, чем настройка стимулов: полезное общественное поведение может не распространяться, если его результаты не становятся доступными для обучения других Actors; при этом опасная среда может сделать отказ от участия рациональнее даже хорошо вознаграждаемого восстановления.


## Эволюция институтов v0.6

Теперь могут изменяться не только стратегии Actors, но и сами правила. GovernanceCell сравнивает соседние институциональные bundles по независимым результатам: fulfillment, harm, неравенство доступа, доля EXIT и coalition-outsider gap. Pareto-режим дополняется экспериментальным rights-floor proxy и требует путь пересмотра для усиливающих ограничения изменений.

В модели также намеренно сохранены плохие comparator-режимы, чтобы harm-only ratchet и самолегитимирующиеся коалиционные предпочтения можно было наблюдать экспериментально, а не исключать предположением.


## Эндогенная эволюция институтов v0.6

Институциональный слой позволяет менять bundles правил в ответ на агрегированные результаты системы, не превращая человека в объект оптимизации. Правила изменяются по осям evidence-sharing, containment, поддержки Repair, отношения к коалициям и возможности пересмотра.

Предпочтительный экспериментальный режим — многокритериальное Pareto-принятие, ограниченное rights-floor proxy и review gate. Для сравнения сохранены два намеренно небезопасных режима: оптимизация только harm и самолегитимирующееся коалиционное управление.

**Институт может обучаться; rights floor не является переменной оптимизации.**


### Результаты эволюции институтов

v0.6 показывает, что институциональная устойчивость зависит не только от содержания правила, но и от **основания, по которому оно выбирается**. Оптимизация только harm ушла в изменение несвязанных институциональных осей. Более строгий rights-floor proxy отклонил 13 кандидатов, но допустил три другие адаптации — неотменяемое ограничение не обязано замораживать обучение. Independent review gate заблокировал 12 restrictive-предложений и сохранил bundle стабильным.

Особенно важен G06: самолегитимирующееся управление выбрало формально общее правило evidence-sharing не потому, что оно «коалиционное», а потому что оно увеличивало долю коалиции. Следовательно, institutional capture не обязан выглядеть как открытая дискриминационная привилегия.

**Содержание правила ≠ основание полномочия на его принятие.**


## Конституционная устойчивость v0.7

После эволюции институтов добавлен конституционный мета-уровень. Последовательность по отдельности допустимых поправок может оказаться опасной, даже если каждый шаг мал и наблюдаемые общественные показатели всё ещё находятся внутри rights-floor proxy.

Поэтому модель различает **локальную законность поправки** и **кумулятивную легитимность траектории**. Отдельно отслеживаются scope полномочий, независимость review, прочность rights floor, сложность внесения поправок, прозрачность и обратимость полномочий; временные полномочия могут автоматически откатываться по sunset.

Центральный инвариант:

**Legitimate Rule Change != Legitimate Accumulation of Power / Законность отдельного изменения ≠ легитимность накопленного перераспределения власти.**


### Результаты конституционной устойчивости

Эксперименты v0.7 показали, что хорошие наблюдаемые общественные результаты не означают здоровую конституционную структуру. В C06 scope полномочий вырос с 0,30 до 0,75, при этом модельные fulfillment, harm, exit, access-Gini и outsider-gap вообще не ухудшились. В C09 прочность rights floor снизилась с 0,90 до 0,60 без немедленного нарушения outcome-порогов, а в C11 amendment friction упала с 0,80 до 0,35.

Обратные сценарии тоже подтверждены: C02 разрешает несколько полезных изменений, но блокирует шаг, пересекающий кумулятивную границу; C04 автоматически откатывает временные полномочия по sunset; C07 восстанавливает унаследованное captured-state последовательностью ограниченных поправок.

Итоговый принцип: **Outcome Health != Constitutional Health / Хорошие результаты ≠ здоровая структура власти; Local Legality != Cumulative Legitimacy.**


## Динамический институциональный захват и восстановление v0.9

Эксперименты v0.9 разделяют фактический граф контроля и граф, доступный наблюдателю. Это позволяет моделировать захват до его раскрытия, задержку обнаружения, формальную ротацию проверяющих без изменения источника контроля, независимый резервный контроль, колебания между захватом и восстановлением, а также ложное восстановление, когда видимые зависимости устранены, но скрытый control path остаётся активным.

Главный вывод этого слоя: независимость института зависит от траектории. Удаление видимой связи или смена названий проверяющих ещё не доказывают восстановление, пока не изменились фактические источники контроля.


## Institutional Epistemics / Доказательство институциональной независимости v1.0

Этот слой исследует уже не только независимость института, но и то, **какое evidence позволяет обоснованно считать его независимым**. Синтетический ground truth доступен только экспериментальному oracle и недоступен самому механизму оценки.

Evidence ограничено конкретными проверяющими, измерениями контроля и сроком действия. Простое количество источников не считается независимым подтверждением: сначала источники сворачиваются по общим источникам контроля. Противоречивое независимо подтверждённое evidence переводит вывод в неопределённое состояние, а не в автоматическое обвинение.

Модель допускает как ложную уверенность в независимости, так и ложноположительный сигнал захвата. Поэтому уверенность системы не подменяется истиной, а любой вывод остаётся ограниченным областью, временем и доступным evidence.


### Экспериментальные результаты v1.0

Все 14 эталонных сценариев прошли. Теперь явно разделены три вещи.

1. **Уверенность evidence не равна ground truth.** K05 показывает ложную уверенность в независимости, а K11 — ложноположительный сигнал захвата.
2. **Множество источников не равно независимости источников.** В K02 три номинальных источника сворачиваются в один эффективный кластер, поскольку имеют общий источник контроля.
3. **Evidence устаревает в обе стороны.** K09 показывает, как реальный захват опережает благоприятное evidence; K13 — как реальное восстановление опережает всё ещё действующее негативное evidence.

Поэтому институциональная память не должна незаметно превращаться ни в постоянное доверие, ни в постоянную стигму.


## Активная институциональная верификация / Ограниченный поиск доказательств v1.1

Поверх оценки v1.0 добавлен ограниченный поиск evidence: scoped experimental search lease, независимые authority/privacy gates, адресные перепроверки, свежесть происхождения источников и допустимая остановка при оставшейся неопределённости. Три policy и 32 сценария сохраняют пропуски capture, ложную уверенность, ложноположительные сигналы и конечные свидетельства зацикливания поиска. Runtime authority и Stable Core promotion не создаются.
