# Испытания Personal Anchor: adversarial v0.1

Задача #1043; связанные направления #1021 и #943.
Исходный main: `e778ae34ed5c03c5b862c45c33b7f9a23d3438a6`.

В набор испытаний включены предложения из обзора от 16 ноября 2026 года.
[Полная матрица и воспроизводимый протокол](README.md) разделяют исполняемые
регрессии существующих валидаторов и ещё не выполненные эксперименты с реальным
PCC/голосовым детектором.

| Направление | Что проверяется сейчас | Что ещё не выполнено |
| --- | --- | --- |
| Просроченный вызов, задержка очистки | Сохранённая запись отклоняется при повторной оценке после срока, даже с пересчитанным хэшем | Реальная очередь PCC под нагрузкой и граница фактического исполнения |
| Отзыв основания | Текущий отказ admission или отозванный lease запрещает действие при свежем ответе | Сквозное получение актуального отзыва |
| Ротация ключа/контроля | Привязка к изменённому approval/permit; старое вложенное основание не проходит | Настоящая ротация ключей, подписи и непрерывность человека |
| Новый intent/target | Старый результат не подходит к новому target | Динамический PCC и проверка намерения |
| Полная утечка истории | Зарегистрирован сценарий: атакующий знает все факты, используемые в вопросах | Эксперимент с действующим verifier; правильное знание прошлого не считается proof of person |
| Повтор/ретрансляция ответа | Проверяется заявленный consumed flag | Глобальное одноразовое потребление, nonce, канал и защита от live relay |
| Перезапись, неизвестный синтез, уверенный ошибочный допуск | Синтетический «принятый ответ» не обходит истёкшее полномочие | Записи, реальный детектор, независимые выборки и измерение FAR/FRR |
| Ошибка и восстановление | Допускается сужение ARAE; один неудачный challenge не исключает человека; моделируемое восстановление сохраняется | Проверка реальных источников и их независимости |
| Минимальное раскрытие | Зарегистрирован отдельный сценарий | Испытание selective disclosure без обязательной полной истории и тотальной телеметрии |

Следующий [исполняемый эксперимент](lifecycle-v0.1/README.ru.md) добавляет 16
последовательностей событий / 32 прогона: очередь, смена текущего основания и
модельного времени, привязки контекста и локальный повтор ответа. Сохранены
фактический вывод и отрицательный контроль с кешированным состоянием.
Все реальные сквозные испытания таблицы остаются **NOT_EXECUTED**.

Запуск:

[Интерфейс для ИИ-агентов](agent-v0.1/README.ru.md) добавляет каталог, строгий JSON,
запуск, сравнение и replay через CLI и MCP stdio. Это доступ к синтетической
лаборатории; все реальные сквозные статусы остаются NOT_EXECUTED.

```bash
python -m unittest discover -s schemas/ecosystem/uu-society/v0.1/harness -p test_personal_anchor_trials.py -v
node --test schemas/ecosystem/uu-society/v0.1/harness/test_personal_anchor_authority.js
```

Проверки используют существующие `apply_event` и `validateDecision`.
Модифицированные записи пересчитывают хэш: отказ должен возникать именно на
сроке, актуальном статусе или привязке, а не только из-за повреждённого digest.
Положительные контроли проверяют, что валидатор не отвергает всё подряд.

**Предел доказательности:** это проверки контрактов на синтетических данных.
Модель не распознаёт человека, не проверяет голос и не доказывает независимость
свидетелей. Самосогласованные записи с заново рассчитанными публичными хэшами
принимаются существующим offline seam — это явно сохранённый контроль предела,
а не доказательство живой личности. Актуальные время и admission должен отдельно
обеспечить будущий адаптер. Сравнения текущего Node seam включают граничный момент;
отказ проверяется через одну миллисекунду после срока.

Статус всех сквозных испытаний — **NOT_EXECUTED**. Голосовой эксперимент требует
зафиксированной версии модели и весов, записей с разрешённым использованием,
разделения обучения/калибровки/теста, заранее выбранной рабочей точки и отдельных
результатов для перезаписи, неизвестных синтезаторов и уверенных ложных допусков.
Нельзя переносить EER детектора в вероятность захвата аккаунта или объявлять
устойчивость к полной утечке истории без отдельного эксперимента.

Источники: [HashiCorp HCSEC-2026-59, 13.11.2026](https://discuss.hashicorp.com/t/hcsec-2026-59-expired-vault-login-mfa-requests-may-remain-redeemable/78257)
и [Küçük et al., 11.11.2026](https://doi.org/10.1007/s44564-026-00042-x).
Это внешние результаты; воспроизведение Vault и голосовой модели здесь не
выполнялось. Реальный Personal Anchor/PCC не реализуется этим инкрементом,
задача #1021 остаётся открытой.
