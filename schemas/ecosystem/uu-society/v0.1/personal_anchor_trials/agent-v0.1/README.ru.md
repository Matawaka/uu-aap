# Интерфейс эксперимента для ИИ-агентов v0.1

Задача #1047. Зависимость — PR #1046, точная версия движка:
`0e0f8924c6df4cc9b8b4a0055a1ea3c275ef4a0b`.
Его интеграция в main не предполагается автоматически.

Реализованы JSON CLI и локальный MCP stdio сервер. Оба вызывают один неизменённый
синтетический движок. [Полный контракт и ограничения](README.md).

[Component Manifest](component-manifest.json) привязан к фактическому коммиту
реализации `ce55816ab7d9be50626af2c75d576d971b6c21e0`. Проверка этих метаданных
сама по себе не запускает компонент и не подтверждает его поведение.

| Инструмент | Назначение |
| --- | --- |
| `experiment.describe` | Манифест, ограничения, схемы, каталог 16 сценариев и привязка к исходникам |
| `experiment.run` | Один режим готового или собственного сценария |
| `experiment.compare` | Одинаковый сценарий в текущем и намеренно небезопасном кешированном режимах |
| `experiment.replay` | Повторное вычисление receipt по тем же исходникам |

Из корня репозитория:

```bash
cd schemas/ecosystem/uu-society/v0.1/personal_anchor_trials/agent-v0.1
npm ci --ignore-scripts --no-audit --no-fund
node agent-cli.js < examples/describe.request.json
node agent-cli.js < examples/compare.request.json
node agent-cli.js < examples/custom.request.json
node examples/mcp-client.js
```

Нужен Node.js 22+. CLI получает один JSON-документ через stdin до EOF и
возвращает один JSON через stdout. Код выхода 0 — COMPLETED, 2 — ERROR.
Дополнительные аргументы командной строки, включая `--write-reference`, не
принимаются. Текущий каталог вызывающего процесса не влияет на поиск файлов.

Для MCP хост запускает `node` с абсолютным путём к `mcp-server.js`. Пример клиента
сам обнаруживает инструменты, читает каталог, запускает сравнение и воспроизводит
receipt. Публичный HTTP-сервис и публикация в реестр здесь не создаются.

Пример запроса:

```json
{"interface_version":"0.1","operation":"experiment.compare","arguments":{"scenario_id":"L02"}}
```

Вместо `scenario_id` агент может передать `scenario` с собственным id и
последовательностью событий. События — только данные фиксированного словаря.
Чужие команды, код, пути, URL, `expected` и поля расширения полномочий отклоняются.
Каждый вызов начинает новый эксперимент; состояние между клиентами не переносится.

Результат разделяет завершение вычисления, пригодность ответа и готовность
контракта действия. COMPLETED не означает разрешение. Совпадение с ожидаемым
результатом небезопасного контрольного режима тоже не разрешает действие.

Собственная гипотеза агента сохраняется как `UNASSESSED_CALLER_STATEMENT`.
Собственный сценарий получает `NO_TRUSTED_EXPECTATION`, даже если его id совпадает
с id эталона. Проверяемые ожидания берутся только из закреплённого каталога.

Receipt связывает принятый разобранный вход, хэши исходников и фактический выход.
Replay заново вычисляет результат и сравнивает весь receipt. Подмена результата
не проходит даже после пересчёта публичных хэшей. При изменении входа корректный
новый receipt описывает новый эксперимент; подлинность автора этим не доказывается.

Все **18 тестов интерфейса** проверены локально, включая отдельные процессы CLI
и MCP SDK-клиента. Проверены режимы 2026-07-28 и 2025-11-25 с SDK 2.4.0.
Это не независимый внешний аудит и не подтверждение всех MCP-хостов.

Ограничения: запрос 512 КиБ, сценарий 64 КиБ, receipt 384 КиБ, глубина 32,
20 000 узлов; движок — 128 событий, 64 заявки и 256 квитанций на режим.
JSON-выход и буфер MCP-кадра ограничены 1 МиБ. Превышение — ошибка.

Исходники движка закреплены по SHA-256; fingerprint интерфейса включает код,
схему и lockfile. Изменение файлов уже запущенного интерфейса вызывает отказ до
перезапуска. Подписи, доверенное время, независимость источника и реальная
личность не доказываются; все реальные PCC/биометрические испытания остаются
NOT_EXECUTED. Доступность инструмента и READY не создают полномочий.
