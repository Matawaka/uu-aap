# Исполняемый эксперимент жизненного цикла ответа v0.1

Задача #1045; продолжение смерженного #1044. Основа:
`7ff2a7c3e46211f57ee038e626c1a6d1e24e1940`.

[Полное описание](README.md) · [Матрица испытаний](../README.ru.md)

Теперь проверяется последовательность: запрос сохранён в очереди → проходит
время или меняется основание → приходит ответ → вызывается существующий Execute
Revalidation. Это автономный синтетический эксперимент с модельными часами и
источником полномочий. Реальный PCC, голосовой детектор и внешнее действие не
запускаются.

Каждый из **16 сценариев** исполнен в двух режимах, всего **32 прогона**:

- `fresh_boundary` получает текущее модельное время, контекст и admission;
- `cached_boundary` намеренно использует состояние первого этапа.

В **11 сценариях** режимы дали разные результаты. Это варианты одного класса
ошибок кеширования, а не одиннадцать новых уязвимостей продукта. Небезопасный
режим явно обозначен как экспериментальный контроль.

| Испытание | Наблюдение |
| --- | --- |
| Просрочка и очередь | Сохранение записи и задержка очистки не продлевают срок при повторной проверке |
| Отзыв или недоступность основания | Текущее отрицательное/недоступное состояние не заменяется прошлым успехом |
| Версия контроля, approval/permit, target и intent | Старый ответ теряет актуальность при изменении связанного контекста |
| Запрос после ротации | Новая заявка с текущими модельными привязками остаётся положительным контролем |
| Неверный nonce и повтор ответа | Чужой nonce не закрывает правильный запрос; повтор принятого ответа отклоняется локально |
| Публичное прошлое и уверенность 0,999999 | Наблюдение не становится доказательством человека или новым полномочием |
| Ошибочный ответ | Сохраняется как evidence без вывода о виновности; новый запрос остаётся возможен |

В L07/L15 ответ уже просрочен, а контракт действия ещё имеет статус READY.
Эти состояния записаны раздельно. READY не доказывает личностную непрерывность
и не создаёт ActionPermit.

Используется настоящий существующий валидатор; хэши изменённых записей
пересчитываются. Сохранённый record первого этапа не переписывается. Три исходных
файла закреплены по SHA-256. Фактический вывод сохранён в
[reference-results.json](reference-results.json); ожидания сценариев определены
до запуска. Проверка воспроизведения не перезаписывает результат.

```bash
node schemas/ecosystem/uu-society/v0.1/personal_anchor_trials/lifecycle-v0.1/run-lifecycle-trials.js --check-reference
node --test schemas/ecosystem/uu-society/v0.1/personal_anchor_trials/lifecycle-v0.1/test-lifecycle-trials.js
```

**24 тестовые записи Node проходят**, включая проверки пяти полей привязки и
четыре намеренно внесённых дефекта. Фиксированные ожидания обнаруживают замену
текущего состояния кешем, остановку часов завершения, отключение защиты от
локального повтора и превращение уверенности в доказательство личности.

Предел доказательности: очередь ограничена 64 заявками, receipt — 256; это не
конкурентный нагрузочный тест. Часы модельные, nonce публичный и детерминированный,
версии контроля — числа. Подписи, реальное владение ключом, distributed replay,
сохранность после перезапуска и защита от live relay не доказаны. Метаданные
публичного ответа воспроизводимы — L14 сохраняет этот отрицательный контроль.

Срок модельного ответа полуоткрытый (`now < expires`); прежнее включение
граничного момента в source-bound проверки валидатора не изменено. Это условия
эксперимента, не новая production policy.

Полная компрометация истории, настоящая ротация ключей и голосовые испытания
остаются **NOT_EXECUTED** до появления конкретного subject/adapter, актуального
источника/часов, реальных данных и независимого воспроизведения. FAR/FRR не
измеряются на синтетических метках. #1021 остаётся открытой.
