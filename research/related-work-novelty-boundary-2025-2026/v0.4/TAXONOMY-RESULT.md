## Why the broad taxonomy claim fails

### StateBench already supplies a multi-class executable taxonomy

StateBench predates the public UU-AAP anchor and tests several state/authority failure classes under one conformance suite: resurrection, hallucination, scope leak, stale reasoning, authority violation and temporal decay.

So a claim such as "Matawaka is the first framework to classify multiple semantic state/authority failures" is not supportable.

### WEXP already supplies verifier-enforced non-inflation across multiple content bases

WEXP predates the public anchor and uses one verifier discipline over `observation`, `intent`, `invocation` and `execution`. Its structural order is explicitly not entailment, and its normative rules prohibit several of the exact promotions that a broad Matawaka semantic-escalation claim would cover.

So a claim such as "Matawaka is the first protocol to prevent valid evidence at one semantic depth from being promoted to another" is also not supportable.

### Specialized named failures cover further classes

AIRGuard names and tests authority confusion. CAP+PCL benchmarks declared-context provenance failure. APL names semantic overclaim/decontextualization/frame laundering. Causality Laundering names and tests causal leakage beyond flat provenance. These are independent predecessor lines, not derivative evidence for Matawaka.

## What may still be worth researching

The exact bounded corpus did **not** reveal one implementation that combines all of the following in a single machine-checkable mutation/oracle format:

1. epistemic promotion (`available/observed -> considered/intended`);
2. semantic-scope promotion (`narrow evidence -> broader claim`);
3. trust/authority promotion (`context/identity -> authority`);
4. review promotion (`approval/review -> current execution permission`);
5. action-depth promotion (`intent/permit/invocation -> execution/effect`);
6. causal promotion (`provenance/dependency -> causality`).

That absence is not proof of novelty. It only defines a possible **integration/evaluation gap**.

A defensible next research hypothesis is therefore:

> A cross-domain adversarial benchmark may be useful if it can show, empirically, that one typed mutation framework detects semantic-promotion failures across several independent governance axes better than composing existing specialized benchmarks or validators.

The word **better** is essential. Merely collecting existing failure modes under one name would not be a research contribution.

## Falsifiable next experiment

A successor should construct a small benchmark in which the same base scenario is mutated along orthogonal semantic axes. For example:

```text
exact evidence
  -> broaden scope                    [APL-like]
  -> convert untrusted context to authority [AIRGuard-like]
  -> resurrect stale authorization    [StateBench/EAL-like]
  -> convert approval to execution    [WEXP/AAC-like]
  -> convert invocation to effect     [WEXP/QIK-like]
  -> convert provenance to causality  [Cheney/ARM-like]
```

Then compare at least:

- a generic Matawaka typed-boundary oracle;
- existing specialized validators where reusable;
- a naive schema-validity baseline;
- an LLM-only policy judge;
- a composition of specialized checks.

Candidate outcome metrics:

- semantic-escalation detection recall by promotion class;
- false-positive rate on legitimate cross-layer transitions;
- cross-domain portability;
- evidence required per verdict;
- implementation overhead;
- whether one shared oracle catches faults missed by a composition of specialized controls.

If the unified oracle does not outperform or simplify the existing composition in a meaningful way, the integration candidate should be rejected.

## Positioning consequence

After v0.1–v0.4 pressure, the safe research posture is:

**Matawaka is not claimed as a new foundational logic or the origin of semantic non-escalation. Its remaining research opportunity is to test whether a unified, typed, cross-domain conformance discipline can operationalize several already-known non-inference boundaries more coherently or effectively for AI-governance systems.**
