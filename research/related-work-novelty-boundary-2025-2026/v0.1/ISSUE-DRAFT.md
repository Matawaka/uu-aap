## Goal

Create a bounded, machine-checkable related-work and novelty-boundary audit for public 2025–2026 work that overlaps with UU-AAP, PoAI, Matawaka agent authority/action boundaries, C2PA/CAWG interoperability, decision provenance, transparency/non-equivocation, and human–AI authorship.

The audit must narrow broad novelty claims where public predecessors exist and preserve only exact, falsifiable `NOVELTY_CANDIDATE` claims where an equivalent materialization is not found in the bounded corpus.

## Required distinctions

```text
public predecessor != complete prior-art search
semantic overlap != derivation
post-publication convergence != prior art against the public Matawaka anchor
novelty candidate != novelty established
research audit != patentability opinion
research audit != freedom-to-operate opinion
Internet-Draft != IETF consensus
GitHub proposal != standards adoption
preprint != peer-reviewed publication
```

## Required package

- annotated source ledger with public dates, source maturity, overlap and non-overlap;
- closed machine-readable schemas;
- claim matrix classifying crowded, overlapped and candidate claims;
- fail-closed cross-document validator;
- hostile tests against temporal and semantic promotion;
- human-readable novelty boundary and annotated sources;
- read-only CI restricted to the audit package.

## Acceptance boundary

The audit must explicitly reject broad novelty claims for at least:

- AI-contribution disclosure;
- `Provenance != Permission`;
- generic pre-action agent authorization;
- delegation/scope narrowing;
- execution receipts;
- transparency/non-equivocation;
- ordinary decision-time evidence traces.

Candidate claims may remain only if they include explicit forbidden claims and required next evidence.

Current candidate family under test:

- Semantic Non-Escalation under Heterogeneous Evidence Composition;
- machine-readable `non_effects` as common receipt semantics;
- `Available Intelligence != Considered Intelligence != Authority`;
- end-to-end seven-layer typed semantic continuity;
- cross-domain authorship-to-action semantic reuse.

## Non-effects

No Stable Core/SPEC/PRINCIPLES/PoAI Genesis/C2PA evidence mutation. No release/tag. No runtime activation. No external standard submission. No patent novelty/patentability/FTO/non-infringement conclusion. No world-first claim. No influence/copying inference.
