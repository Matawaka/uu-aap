## Purpose

The question is no longer whether Matawaka differs from other 2025–2026 AI-agent proposals. The question is whether the surviving semantics were already present, in substance, in older security logic, programming-language theory, provenance models, rational-agent theory and decision science.

- secure information flow / noninterference;
- effect systems, frame conditions and local reasoning;
- authorization logics and proof-carrying authorization;
- belief, awareness, intention and deontic agent architectures;
- awareness and consideration-set theory;
- provenance algebras and domain-neutral provenance;
- actor/plan/delegation/responsibility provenance;
- signed multi-step action/artifact supply-chain provenance.
