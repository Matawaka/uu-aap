# rgdd attributed project-history corroboration v0.1

This additive successor to merged #949 composes two different evidence classes without rewriting either predecessor:

1. frozen #945: five of six public operator labels corroborated by the narrower operator-origin evidence classes;
2. this package: two distinct immutable Sigsum project-history blobs whose status items are explicitly attributed to handle `rgdd` and bind that handle to exact witness name `rgdd.se/poc-witness`.

The new source class is:

`PUBLIC_PROJECT_MINUTES_ATTRIBUTED_TO_OPERATOR_HANDLE`

It is deliberately **not** classified as operator-origin publication. The verifier extracts only the status item beginning with the exact `rgdd:` attribution and forbids cross-speaker or cross-file text composition.

A strong result means only that the six public labels have corroborating operator-attributed public evidence across the frozen predecessor plus the two qualifying `rgdd` history records. It does not establish legal identity, cryptographic identity, domain control, current activity, continuous availability, organizational independence, non-equivocation, completeness, truth, authority, or remediation.

The upstream sources are fetched read-only from exact `sigsum/sigsum` commit `e3ee15ecfb343e083398bf05bc5c5fb55e2d0783` and are accepted only when their Git blobs match the profile exactly.

`Trigger != Authorization` remains unchanged.
