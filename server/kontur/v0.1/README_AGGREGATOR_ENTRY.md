# KONTUR readiness composition entrypoint

The persistent Responsibility Kernel is activated only from a typed readiness frontier.

Canonical v0.1 readiness path:

`independent evidence -> KONTURReadinessEvidenceSet -> KONTURReadinessAggregationReceipt -> KONTURReadinessSignal -> KONTURReadinessAcceptanceReceipt -> KONTURActivationFrontierReceipt -> human activation boundary`

See [`READINESS_AGGREGATOR.md`](./READINESS_AGGREGATOR.md) for the full contract.

A positive activation-frontier receipt means **the canonical activation prompt may be requested**. It does not activate the kernel and does not create a responsibility state.
